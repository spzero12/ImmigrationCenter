# Миссия проекта

## Что это

Корпоративный портал для учёта иностранных сотрудников: ведение личных данных
работников, оформление миграционных карт и подготовка пакета документов,
необходимого для соблюдения миграционного законодательства.

## Проблема

Компании, привлекающие иностранную рабочую силу, обязаны вести точный учёт
сроков пребывания, разрешительных документов и уведомлений в контролирующие
органы. Ручной учёт в таблицах приводит к пропущенным срокам, утере
документов и штрафам за нарушение миграционного режима.

## Кому нужен портал

- HR-отдел и кадровое делопроизводство — ведение карточек сотрудников.
- Миграционный/юридический специалист — контроль сроков, подготовка карт и
  уведомлений.
- Руководство — сводная отчётность по статусу иностранных сотрудников.

## Цели проекта

1. Единая база иностранных сотрудников компании (личные данные, документы,
   сроки действия разрешений).
2. Формирование миграционных карт и сопутствующих документов по шаблонам.
3. Контроль сроков (виза, патент, регистрация) с напоминаниями о
   приближающихся дедлайнах.
4. Разграничение доступа по ролям (HR, юрист, администратор, руководитель).
5. История изменений и аудит действий с документами сотрудника.

## Критерии успеха

- Все данные по иностранным сотрудникам ведутся в одном месте, без Excel.
- Ни одно разрешение/регистрация не просрочены из-за отсутствия напоминания.
- Формирование пакета документов на сотрудника занимает минуты, а не часы.
