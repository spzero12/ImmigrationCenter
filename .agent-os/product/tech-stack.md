# Технологический стек

## Backend

- **PHP 8.x** — основной язык серверной части.
- **MySQL / MariaDB** — хранение данных о сотрудниках, документах, сроках.
- **Composer** — управление зависимостями PHP.
- Собственная лёгкая архитектура (без тяжёлого фреймворка на старте):
  `includes/` для общих частей (header/footer, подключение к БД), отдельные
  PHP-скрипты как точки входа/контроллеры. При росте проекта — переход на
  Laravel или Symfony, если понадобится полноценный MVC, ORM и миграции.

## Frontend

- **HTML5 / CSS3** — вёрстка.
- **jQuery 3.x** — работа с DOM, AJAX-запросы к PHP-эндпоинтам без перезагрузки
  страницы (например, обновление статуса документа, фильтрация списка
  сотрудников).
- **Bootstrap 5** (план) — готовые компоненты UI (таблицы, формы, модальные
  окна) для админ-панели портала.

## Документы и отчётность
- есть готовые шаблоны word docx
- **dompdf** или **mPDF** (план) — генерация PDF миграционных карт и
  сопутствующих документов по шаблонам.
- **PhpSpreadsheet** (план, опционально) — экспорт сводных отчётов в Excel.

## Авторизация и роли

- Сессии PHP (`$_SESSION`) для аутентификации.
- Ролевая модель: администратор, HR, юрист/миграционный специалист,
  руководитель (просмотр отчётов).

## Инфраструктура

- Локальная разработка: встроенный сервер PHP (`php -S localhost:8000`).
- Хранение файлов (сканы документов) — локальная файловая система
  (`/uploads`), с возможностью перехода на S3-совместимое хранилище при
  необходимости.

## Что намеренно не используется на старте

- Тяжёлые JS-фреймворки (React/Vue) — интерфейс достаточно прост для jQuery.
- Микросервисная архитектура — монолит на PHP полностью покрывает задачи
  портала на этом этапе.
