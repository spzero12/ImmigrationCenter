# Спецификация: Дизайн-система портала

Не привязана к конкретному этапу [roadmap](../../product/roadmap.md) — сквозная
фича, затрагивает все существующие и будущие страницы.

## Решения (по ответам на вопросы)

- **Стиль**: плотная админ-панель — приоритет плотности данных над
  «воздухом», как в типичной ERP/CRM (много строк на экран, компактные
  отступы).
- **UI-кит**: [Tabler](https://tabler.io) — бесплатная (MIT) админ-тема на
  Bootstrap 5. Подключается через CDN (CSS + JS + иконки), без сборки —
  совместима с текущим стеком PHP + jQuery без изменений в тулчейне.
- **Брендинг**: готового лого/цветов нет — палитра предложена ниже.
- **Адаптивность**: обязательна для мобильных/планшетов (сворачиваемый
  сайдбар — есть в Tabler из коробки).
- **Тёмная тема**: не нужна в этой фиче.

## Палитра (дизайн-токены)

Определена как CSS-переменные в [css/tokens.css](../../../css/tokens.css),
отдельно от Tabler, чтобы переопределять его переменные `--tblr-*`, а не
править исходники темы.

| Токен | Значение | Назначение |
|---|---|---|
| `--color-primary` | `#2563eb` | Акцент, кнопки, ссылки (продолжение текущего синего) |
| `--color-bg` | `#f4f6fa` | Фон страницы |
| `--color-surface` | `#ffffff` | Карточки, таблицы, панели |
| `--color-border` | `#e5e7eb` | Границы, разделители |
| `--color-text` | `#1f2937` | Основной текст |
| `--color-text-muted` | `#6b7280` | Вторичный текст |
| `--color-success` | `#16a34a` | Статус «в порядке» |
| `--color-warning` | `#d97706` | Статус «скоро истекает» |
| `--color-danger` | `#dc2626` | Статус «просрочен» |
| `--color-info` | `#0ea5e9` | Статус «без срока» / нейтральные бейджи |

Цвета `success/warning/danger/info` напрямую переиспользуются для статусов
документов из фичи [migration-documents](../2026-08-20-migration-documents/spec.md)
— единый источник правды для цвета статуса.

## Плотность

- Базовый размер шрифта: `14px` (Tabler по умолчанию `16px`).
- Таблицы — вариант `table-sm` (компактные строки).
- Отступы карточек/форм — уменьшенные варианты Tabler (`card-body` с меньшим
  `padding`, `g-2` вместо `g-3` для сеток форм).

## Layout

Верхний navbar (лого, пользователь, выход) + левый сайдбар с разделами
(«Сотрудники», «Документы») — стандартный layout Tabler для админ-панелей.
На мобильных сайдбар сворачивается в бургер-меню (встроено в Tabler).

## Затрагиваемые страницы

`login.php`, `employees.php`, `employee_form.php`, `documents.php`,
`document_form.php`, `includes/header.php`, `includes/footer.php`.

## Вне рамок этой фичи

- Тёмная тема.
- Кастомное лого/брендинг (нет исходных материалов).
- Изменение бизнес-логики — только вёрстка/стили, существующие
  jQuery-обработчики (`js/employees.js`, `js/documents.js`) должны продолжить
  работать с новой разметкой (проверить используемые ими селекторы).

## Готово на этом шаге

Только спецификация и дизайн-токены (`css/tokens.css`) — файл существует, но
пока никуда не подключён, чтобы не ломать текущий рабочий вид страниц.
Подключение Tabler и переверстка страниц — по чек-листу в
[tasks.md](tasks.md), отдельным шагом.
