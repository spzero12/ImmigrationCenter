# Спецификация: Уникальные поля по типу документа

## Решения

- Хранение: `employee_documents.extra_fields` (JSON) — по аналогии с уже
  существующим `field_overrides`, без новых колонок в БД под каждое поле.
- Набор полей на тип (`DOCUMENT_TYPE_EXTRA_FIELDS` в
  [includes/documents.php](../../../includes/documents.php)), предложен
  на основе реальной практики:

| Тип | Поля |
|---|---|
| Паспорт | Место рождения |
| Виза | Категория визы, Кратность |
| Патент на работу | Профессия, Регион действия |
| Разрешение на работу | Профессия, Работодатель |
| Регистрация | Адрес регистрации, Принимающая сторона |

- `document_form.php` — поля рендерятся под каждый тип отдельным блоком,
  JS показывает только блок текущего выбранного типа (тот же паттерн, что
  уже используется для выбора паспорта).
- `documents.php`/`employee_form.php` — колонка «Детали»: заполненные поля
  компактным подписанным списком в одной ячейке (`.extra-field-pairs` в
  [css/style.css](../../../css/style.css)), а не отдельные колонки таблицы.
- Генерация .docx (`document_generate.php`) не тронута — эти поля пока не
  добавлены как плейсхолдеры (вне рамок, можно добавить отдельно).

## Проверено локально

Создание документов каждого типа с заполненными уникальными полями,
отображение в `documents.php` и в списке документов сотрудника,
переключение полей по типу в форме (JS toggle).
