# Шаблоны документов

Сюда кладутся .docx-шаблоны для генерации ([document_generate.php](../document_generate.php)).

Имя файла = тип документа: `passport.docx`, `visa.docx`, `work_patent.docx`,
`work_permit.docx`, `registration.docx` (значения `type` из
`DOCUMENT_TYPE_LABELS` в [includes/documents.php](../includes/documents.php)).

Плейсхолдеры внутри .docx — синтаксис PHPWord `${имя}`, полный список и их
источники — в [.agent-os/specs/2026-08-20-document-generation/spec.md](../.agent-os/specs/2026-08-20-document-generation/spec.md).

Реальных шаблонов от заказчика пока нет. Все пять файлов —
собственные заглушечные шаблоны (сгенерированы через PHPWord, чтобы
плейсхолдеры не были случайно разбиты на отдельные XML-runs, как бывает
при ручном наборе в Word), используют все 19 плейсхолдеров из
спецификации (включая `${organization}`) и отличаются только заголовком
под свой тип. Годятся для проверки механизма генерации и для демонстрации,
но не являются официальными формами — когда появятся реальные шаблоны от
заказчика, заменить эти файлы.
